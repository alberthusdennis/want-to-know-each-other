# 100 Pertanyaan — Kenal Pelan-Pelan

Website interaktif untuk mengenal seseorang lebih dalam melalui 100 pertanyaan ringan hingga reflektif.

## Fitur
- 100 pertanyaan dalam 9 kategori
- 3 mode permainan: Semua, Acak, Pilih Kategori
- Giliran bergantian antara dua orang
- Simpan pertanyaan favorit
- Backup & restore data (biar bisa lanjut kapan saja)

## Cara Pakai
1. Buka website
2. Pilih mode permainan
3. Tarik pertanyaan dan jawab bergantian
4. Kalau obrolan seru, abaikan kartu
5. Download backup setelah selesai

## Teknologi
- HTML, CSS, JavaScript murni
- LocalStorage untuk penyimpanan
- GitHub Pages untuk hosting
